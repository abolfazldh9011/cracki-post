# ربات تلگرامی دانلود اینستاگرام

## نصب

```bash
pip install -r requirements.txt
```

## گرفتن توکن ربات

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده
2. دستور `/newbot` رو بزن و اسم و یوزرنیم دلخواه رو بده
3. توکنی که برات میفرسته رو کپی کن

## اجرا

توکن رو به‌صورت متغیر محیطی ست کن و ربات رو اجرا کن:

```bash
export BOT_TOKEN="123456:ABC-DEF..."
python bot.py
```

یا مستقیماً داخل `bot.py` مقدار `BOT_TOKEN` رو جایگزین کن (برای تست سریع، توصیه نمی‌شه برای پروداکشن).

## نکات مهم

- این ربات فقط پست‌ها و ریلزهای **پابلیک** رو می‌تونه دانلود کنه. برای اکانت‌های خصوصی
  باید فایل کوکی مرورگر (`cookies.txt`) رو استخراج کنی و در `ydl_opts` داخل `bot.py`
  خط `cookiefile` رو فعال کنی.
- محدودیت پیش‌فرض تلگرام برای ارسال فایل توسط ربات‌های معمولی **۵۰ مگابایت** است.
  برای فایل‌های بزرگ‌تر باید یک [Local Bot API Server](https://github.com/tdlib/telegram-bot-api)
  راه‌اندازی کنی که محدودیت رو تا ۲ گیگابایت افزایش می‌ده.
- اینستاگرام گاهی الگوریتم‌های ضد اسکرپینگ خودش رو تغییر می‌ده؛ اگه دانلود با خطا مواجه شد،
  ابتدا `yt-dlp` رو آپدیت کن:
  ```bash
  pip install -U yt-dlp
  ```

## اجرای همیشگی روی سرور (اختیاری)

برای اینکه ربات ۲۴ ساعته روشن بمونه، می‌تونی از `systemd`، `screen`،
یا سرویس‌هایی مثل Railway / VPS استفاده کنی و دستور بالا رو به‌صورت
پس‌زمینه اجرا کنی.

## دیپلوی روی Railway

پروژه شامل `Procfile` و `runtime.txt` هست و آماده‌ی دیپلوی روی Railway‌ه.

### روش ۱: از طریق گیت‌هاب (پیشنهادی)

1. یه ریپوی گیت‌هاب بساز و کل محتوای این پوشه (`bot.py`, `requirements.txt`,
   `Procfile`, `runtime.txt`, `.gitignore`) رو داخلش push کن.
2. وارد [railway.app](https://railway.app) شو و با گیت‌هاب لاگین کن.
3. **New Project → Deploy from GitHub repo** رو بزن و ریپوی خودت رو انتخاب کن.
4. Railway به‌صورت خودکار `Procfile` رو تشخیص می‌ده و به‌عنوان یه **Worker** اجراش می‌کنه
   (چون ربات polling‌ه، نیازی به پورت یا وب‌سرور نداره).
5. برو به تب **Variables** پروژه و متغیر زیر رو اضافه کن:
   ```
   BOT_TOKEN=توکن-رباتت
   ```
6. Railway به‌محض ست‌شدن متغیر، دوباره دیپلوی می‌کنه و ربات روشن می‌شه. ✅

### روش ۲: از طریق Railway CLI

```bash
npm i -g @railway/cli
railway login
cd insta_bot
railway init
railway variables set BOT_TOKEN="توکن-رباتت"
railway up
```

### نکات دیپلوی

- حتماً نوع سرویس رو **Worker** بذار نه Web، چون ربات پورتی باز نمی‌کنه.
- پوشه‌ی `downloads/` روی هاست‌های Railway موقتی‌ست (ephemeral)؛ فایل‌ها بعد از
  ارسال با `os.remove` پاک می‌شن، پس مشکلی برای فضای دیسک پیش نمیاد.
- اگه لاگ خطای `Conflict: terminated by other getUpdates request` دیدی یعنی
  چند نسخه از ربات هم‌زمان با یه توکن اجرا شدن (مثلاً هم لوکال هم روی Railway)؛
  یکی رو متوقف کن.
